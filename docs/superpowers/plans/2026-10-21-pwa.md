# M12 PWA Support Plan

**Goal:** Make GrowLog installable with safe offline behavior while preventing sensitive API or server-rendered household data from entering browser caches.

**Architecture:** Next metadata exposes a standalone manifest with 192/512 maskable icons. A small client registrar installs `/sw.js` and checks for updates. The service worker caches only the public offline fallback, icons, manifest, and immutable `/_next/static/` assets; navigations are network-only with offline fallback, and `/api/` requests bypass Cache Storage. Global API headers enforce private no-store responses.
